Door vs Pages

The page reads /ant/v1/data/public/<address>. On the relay host that path is same-origin. GitHub Pages has no /ant proxy, so skaists.dev uses relay.skaists.dev (CORS grants that origin). Local poke: ?door=same behind a proxy, or ?door=relay.

Door vs WASM

The door is a bridge, not the destination. Direct in-page protocol waits on Autonomi’s WASM client. Until then this is a GET-only read of public data. The estate holds no keys here.
