How the page asks

For the builder

Builder

The page reads /ant/v1/data/public/<address>. On the relay host that path is same-origin. On GitHub Pages the same path is a Pages 404, so the page uses the relay door (CORS grants https://skaists.dev). Local poke: ?door=same behind a proxy, or ?door=relay.

What this is not

For the cypherpunk

Cypherpunk

The door is a bridge, not the destination. Direct in-page protocol waits on Autonomi’s WASM client. Until then this is a GET-only read of public data. The estate holds no keys here.
