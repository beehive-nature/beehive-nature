## Summary

Cannabinoid product streams represent the highest-value output from hemp biomass. Cannabinoid-rich flower and trim biomass undergo extraction to produce a cascade of products ranging from crude extract to pharmaceutical-grade isolates. This is the most economically significant product stream category, representing an estimated 60–70% of total hemp market value despite utilizing only 5–15% of total plant biomass.

## 1. Input Biomass Specifications

### 1.1 Acceptable Input Grades (per BN Fleet Standard)
| Grade | Description | Cannabinoid Content | Price Tier |
|---|---|---|---|
| **A1** | Premium flower, hand-trimmed | >12% CBD/CBG | Highest |
| **A2** | Standard flower, machine-trimmed | 8–12% CBD/CBG | High |
| **B1** | Trim/biomass (small buds + sugar leaf) | 5–8% CBD/CBG | Medium |
| **B2** | Fan leaf / low-grade biomass | <5% CBD/CBG | Low |

### 1.2 Key Input Parameters
- **Cannabinoid profile** (CBD, CBG, CBC, CBN, THC, THCV, etc.) — determined by cultivar + harvest timing
- **Terpene profile** — determines aroma, flavor, entourage effect potential
- **Moisture content** — optimal 8–12% for extraction
- **Contaminant screening** — pesticides, heavy metals, microbial, mycotoxins [C]

## 2. Extraction Methods

### 2.1 Supercritical CO₂ Extraction
| Parameter | Detail |
|---|---|
| **Mechanism** | CO₂ pressurized above critical point (31°C, 73.8 bar) acts as solvent |
| **Selectivity** | Tunable — can target specific cannabinoids/terpenes by adjusting pressure/temp |
| **Yield** | 80–95% of available cannabinoids |
| **Product quality** | Highest — no residual solvent, FDA-approved for food/pharma |
| **Capex** | $100K–$500K+ for industrial systems |
| **Best for** | Premium full-spectrum oils, pharmaceutical-grade products |
| **Limitation** | Slower throughput; high equipment cost |

### 2.2 Ethanol Extraction
| Parameter | Detail |
|---|---|
| **Mechanism** | Food-grade ethanol (200 proof) dissolves cannabinoids + terpenes |
| **Yield** | 85–98% of available cannabinoids |
| **Product quality** | High — winterization removes waxes/lipids |
| **Capex** | $50K–$250K |
| **Best for** | Large-scale distillate production |
| **Limitation** | Extracts chlorophyll (needs winterization); flammability concerns |

### 2.3 Hydrocarbon Extraction (Butane/Propane)
| Parameter | Detail |
|---|---|
| **Mechanism** | BHO/PHO dissolves cannabinoids at low temperatures |
| **Yield** | 75–90% |
| **Product quality** | Excellent terpene preservation; residual solvent testing required |
| **Best for** | Concentrates, high-terpene extracts |
| **Limitation** | Safety/regulatory concerns; not suitable for all jurisdictions |

### 2.4 Solventless (Mechanical)
| Parameter | Detail |
|---|---|
| **Mechanism** | Ice water extraction (bubble hash) or rosin press (heat + pressure) |
| **Yield** | 20–60% (lower but ultra-premium) |
| **Product quality** | Highest purity — no solvents whatsoever |
| **Best for** | Ultra-premium, craft, full-melt concentrates |
| **Limitation** | Low throughput; labor-intensive |

## 3. Product Stream Cascade

```
Cannabinoid-Rich Biomass
        │
   EXTRACTION
        │
   Crude Extract
   ├──→ Winterization → Dewaxed Oil
   │       ├──→ Distillation → Distillate (80-90% CBD)
   │       │       ├──→ Isolation → CBD Isolate (>99%)
   │       │       ├──→ Isolation → CBG Isolate (>99%)
   │       │       ├──→ Isolation → CBN Isolate (>99%)
   │       │       └──→ Formulation → Tinctures, Topicals
   │       └──→ Full-Spectrum Oil (preserve terpenes + minors)
   └──→ Crude → Broad-Spectrum (THC removed)
```

## 4. Product Specifications

### 4.1 CBD Isolate
| Spec | Value |
|---|---|
| **Purity** | ≥99.0% CBD |
| **Form** | Crystalline powder |
| **Appearance** | White to off-white |
| **Cannabinoids** | CBD only; all others removed |
| **Terpenes** | None |
| **Decarboxylation** | Complete (activated CBD) |
| **Typical wholesale** | $300–800/kg (volatile, varies by market) |

### 4.2 Full-Spectrum Distillate
| Spec | Value |
|---|---|
| **CBD content** | 80–90% |
| **Other cannabinoids** | CBG, CBN, CBC, THC (<0.3%) |
| **Terpenes** | 1–5% (may be reintroduced) |
| **Form** | Viscous golden oil |
| **Entourage effect** | Yes — full cannabinoid + terpene synergy |
| **Typical wholesale** | $400–1,200/kg |

### 4.3 Broad-Spectrum Distillate
| Spec | Value |
|---|---|
| **CBD content** | 80–90% |
| **Other cannabinoids** | CBG, CBN, CBC present |
| **THC** | Non-detectable (ND) |
| **Terpenes** | 1–5% |
| **Best for** | Consumers requiring zero THC (drug testing, federal compliance) |

### 4.4 Minor Cannabinoid Isolates
| Cannabinoid | Properties | Market Stage | Indicative Price |
|---|---|---|---|
| **CBG** | "Mother cannabinoid," anti-inflammatory | Growth | $2,000–5,000/kg |
| **CBN** | Sedative, sleep aid | Emerging | $3,000–8,000/kg |
| **CBC** | Anti-inflammatory, mood | Nascent | $4,000–10,000/kg |
| **THCV** | Appetite suppressant, energy | Research | $5,000–15,000/kg |
| **CBDV** | Anti-convulsant (epilepsy research) | Research | $5,000–12,000/kg |

### 4.5 Novel Cannabinoids (Semi-Synthetic)
| Compound | Source | Legal Status | Risk Level |
|---|---|---|---|
| **Delta-8 THC** | CBD → isomerization | Gray market (US state-dependent) | ⚠️ Moderate |
| **HHC** | CBD → hydrogenation | Unregulated (US) | ⚠️ Moderate |
| **THC-O Acetate** | CBD → acetylation | Disputed (DESA) | 🔴 High |
| **THCP** | Synthetic | Research only | 🔴 High |

> ⚠️ **BiGen Note:** Novel cannabinoids lack sufficient clinical safety data. The BN Fleet Canvas LM comprehension gate requires verified understanding of risk profiles before marketplace access to these compounds.

## 5. Quality Assurance & Testing

### Required Testing Panel (per batch)
| Test | Method | Pass Criteria |
|---|---|---|
| **Cannabinoid potency** | HPLC | Quantified CBD/CBG/CBN/CBC/THC |
| **Terpene profile** | GC-MS | Identified + quantified |
| **Residual solvents** | GC-MS | Below USP <467> limits |
| **Pesticides** | LC-MS/MS | Action-level compliance |
| **Heavy metals** | ICP-MS | Pb, As, Cd, Hg below limits |
| **Microbial** | Plating/qPCR | No Salmonella, E. coli; yeast/mold within limits |
| **Mycotoxins** | LC-MS/MS | Aflatoxins, ochratoxin below limits |

> **Commodity Index Note:** Products with full COAs (Certificates of Analysis) from ISO-accredited labs receive premium pricing in the Index. See Entry 11.

## 7. Commodity Index Integration

This product stream feeds the Intercontinental Commodity Index through:
- **Input pricing:** Biomass grades A1–B2 priced per % cannabinoid per pound
- **Output pricing:** Isolate, distillate, full-spectrum priced per kg by purity
- **Processing margin:** Spread between input biomass cost and output product value
- **Regional differentials:** Pricing varies by geography, regulation, supply/demand
