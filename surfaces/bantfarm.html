      🐜 the bANTfarm

      Two living treasuries, one honest window. On one side, the ant colony — the Autonomi storage network our data lives on, and the wallet that feeds it. On the other, SKAISTS · LOVErnment DAO on Vaulta, where the .b names live. This page only reads — it never holds a key, and it can't spend a thing. Type any public address and look.
      the node farm and the two treasuries — ANT on Arbitrum One beside the DAO on Vaulta — read keylessly, live, with every number's source printed under it. the farm feeds the archive; the DAO steers the names; this window watches both.
      Read-only dual-treasury instrument: ERC-20 balanceOf/decimals/totalSupply + eth_getBalance via public Arbitrum RPC (failover), and Vaulta get_account/get_currency_balance via the estate's proven three-host failover. Zero keys, zero write paths, zero custody — the ANT token address is displayed with its re-derive-before-paying caveat because a DISPLAY address must never be promoted to a PAYMENT address by copy-paste habit. Node operations dock locally (antd), never through a hosted page.
