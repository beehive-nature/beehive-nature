# Cross-form fixtures — voucher-escrow

> **Why this lives here and not beside the crate.** The chain hashes in the
> ledger below are 64-hex and trip the secret scanner, and a JSONL data file
> cannot carry a `PUBLIC-CONSTANT` marker without ceasing to be the bytes
> Python wrote. `fixtures/` already carries a founder-ruled, path-scoped
> exemption for exactly this class — generated fixtures whose hex is content
> hashes of public data, never key material (secret-scan.sh, 2026-07-06). Using
> that existing exemption is right; widening it to `*/fixtures/` would have been
> a policy change, and that is not a seat call.

## `python_ledger.jsonl`

**Written by the other form.** Generated by the real in-tree
`scripts/buzz-meter/voucher_escrow.py` — the same engine the box runs — not by
this crate. It is the acceptance evidence for `Escrow::from_jsonl` +
`verify_chain` (proof 18) and for the loader's refusals (proof 19).

Five events, chosen to be adversarial for every divergence that has actually
forked the two forms:

| # | event | what it exercises |
|---|---|---|
| 0 | A deposit, memo-native | the gasless A/Vaulta rail, sender + memo |
| 1 | charge | line items, explicit rate, the 10% tithe as its own line |
| 2 | USDC deposit | the USDC/Base rail: explicit rate + `rate_ref` |
| 3 | deposit, non-ASCII voucher | `café-Ω-voucher`, escaped as Python escapes it |
| 4 | charge | a second charge, so the chain has depth |

Python's own reading of it:

```
balance member-abc      = 29.5600
balance café-Ω-voucher = 1.0000
```

### Why this fixture is the proof, and not a formality

Disable rule 3 — verify by re-serialising structs instead of hashing the stored
bytes — and **proof 18 fails at event 2**. Not at the non-ASCII event, and not
at every float: event 1 carries a 17-significant-digit timestamp and verifies
fine, while event 2's does not.

That is the whole argument for the rule. The divergence is **value-specific and
unpredictable**: you cannot enumerate the forks, so you must stop asking a
serialiser to reproduce bytes that were already written down. A chain verifies
the bytes it stored.

### Replacing this with the box's own ledger

This fixture stands in for a snapshot of the live box ledger (z1.1's side),
which had not arrived when it was written. When that snapshot lands, drop it in
beside this file, point proof 18 at it, and delete this note. Nothing about the
test needs to change — the format is the same because the engine is the same.

**Events only. No secrets, no keys, no admin material** — and any replacement
must be held to the same line.
