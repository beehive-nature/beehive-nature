# PLUR comparison batch — 2026-10-03

18 Kokoro v1.0 int8 recordings cover existing Hindi, French and Spanish words plus English, Hindi, French, Spanish, Italian and Portuguese language-name samples. These are candidates, not promoted defaults. Portuguese uses a Brazilian voice; dialect suitability needs review. The remaining PLUR languages have no Kokoro candidate in this batch. Kokoro's own voice documentation warns about short utterances; this set deliberately tests the real single-word use case.

Model provenance: [Kokoro model card](https://huggingface.co/hexgrad/Kokoro-82M), [voice documentation](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md), [ONNX conversion release](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0), [ONNX runner MIT license at inspected revision](https://github.com/thewh1teagle/kokoro-onnx/blob/3596b26764286a7de9d90c363e988d50578918e5/LICENSE). Upstream model card declares Apache-2.0 and attributes French training data to [SIWIS](https://datashare.ed.ac.uk/handle/10283/2353), CC BY 4.0. Model weights and runtime binaries are not distributed with these WAVs. The output manifest pins the exact model, voices, baseline and candidate audio digests. The Python generator verifies model/voice digests before use. Phonemization uses eSpeak through the ONNX runner, so this is not an independent pronunciation oracle.

Eight contextual sentence drafts were generated by Helsinki-NLP opus-mt-en-fr and opus-mt-en-es. The exact model revisions are in translations.json and pinned in scripts/compare-plur-translations.py. Source cards: https://huggingface.co/Helsinki-NLP/opus-mt-en-fr and https://huggingface.co/Helsinki-NLP/opus-mt-en-es. These drafts do not alter the curated corpus or establish semantic correctness.

Reproduce using Python 3.11, requirements.txt (CPU torch wheel from https://download.pytorch.org/whl/cpu). Download model.onnx and voices.bin from the ONNX release URLs corresponding to kokoro-v1.0.int8.onnx and voices-v1.0.bin, into a directory outside the repository. Run scripts/compare-plur-kokoro.py with that directory as its argument, then scripts/compare-plur-translations.py. Network is needed for model downloads; inference itself ran locally. No private text or microphone audio was sent.

Generation measurements describe this one x86_64 CPU run; they exclude download/model loading, include possible first-item warm-up, and do not compare baseline synthesis speed. Quantization, phonemizer, voice and speed are part of the candidate. No quality winner or general latency claim is made.

The public review form downloads a self-reported draft tied to exact audio hashes. It neither submits nor authenticates a review and never updates the native-review status. A qualified speaker still needs to assess meaning, dialect, stress and intelligibility; publication approval requires separate evidence review.

Headroom repair: the initial float outputs for Hindi exceeded full scale. The renderer now applies only attenuation when needed to keep candidate peaks at or below 0.95 before PCM conversion. sourcePeak and gain are recorded; tests inspect the actual PCM samples. This avoids clipping, but does not establish pronunciation quality.
