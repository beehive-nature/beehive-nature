# hex — the hexagonal rendering path

LAW: **hex is a MODE alongside square, never a replacement.** Nothing in the
square build is removed or silently swapped. The artist picks.

Five standalone modules, pure functions, no DOM at import time, no npm, plain
TypeScript. They plug into the vendored PixelRefiner core later; the quantizer
is passed in as a callback and used UNCHANGED (lattice-agnostic, not forked).

| module | does |
|---|---|
| `hexcoords.ts` | axial (q,r) math: hex↔pixel for pointy-top AND flat-top (size = circumradius), cube rounding, constant 6-neighbour table (no row-parity branching), axial↔offset only at the array storage boundary |
| `hexresample.ts` | square raster → hex cells, AREA-WEIGHTED (supersampled; sub-samples averaged per containing cell in Oklab — estate constants), result handed to the existing quantizer unchanged |
| `hexmorph.ts` | dilate / erode / 1-cell outline (`dilate AND NOT content`) / flood fill — one connectivity (6-neighbour); the square build's 4-vs-8 and sharp/rounded split collapses here |
| `hexdither.ts` | ① serpentine tone-dependent error diffusion per Jodoin & Ostromoukhov, SPIE 5008 (2003), DOI 10.1117/12.473230 — 3 downstream neighbours d10/d-11/d01, mirroring swaps the below targets, full-precision float Oklab buffer; ② ordered dither via a void-and-cluster (Ulichney 1993) blue-noise mask generated OFFLINE over hex axial coordinates (64×64 tileable, deterministic) and baked in |
| `hexrender.ts` | live render = ONE Path2D hex translated+filled per cell, oversized 0.5px and stroked 1px same-colour to kill hairline seams (never crispEdges); SVG export = one `<symbol>` + `<use>` grouped by fill; PNG export = offscreen ×N re-render → toBlob |

## Coefficient-table provenance (read this)

The diffusion ALGORITHM is the published one, exactly — serpentine scan, 3
downstream neighbours (d10 forward, d-11 / d01 below), mirrored below-target
swap on right-to-left lines, tone-dependent triples normalized to sum 1,
levels 128-255 mirrored. The table is now the paper's VERIFIED numbers:
Jodoin & Ostromoukhov, "Halftoning Over a Hexagonal Grid," Proc. SPIE 5008
(2003), DOI 10.1117/12.473230 — 128 rows of integers (~10000 per row), held
in `JODOIN_TABLE_INTS` (swappable constant; tests assert row sums, known
rows, and per-row normalization). The void-and-cluster mask is fully
generated here (`tools/gen-voidcluster.mjs`, deterministic seed, converged,
rank permutation proven).

## Working on this lane

```sh
node tools/build.mjs        # verbatim vendor-ref copy + tsc emit to dist/
node tests/run.mjs          # 51 assertions, every one prints its raw values
node tools/gen-voidcluster.mjs   # regenerate the blue-noise mask (offline)
node tools/serve.mjs        # demo at http://127.0.0.1:8944/demo/
```

- `vendor-ref/` — byte-exact copies of the estate quantizer
  (`PixelRefiner/src/core/{quantizer,colorUtils}.ts` + `shared/types.ts`,
  MIT, mirror verified at commit `bd5c1c7`), regenerated by the build, never
  hand-edited, never forked. The demo compiles and runs against them.
- `demo/` — FUNGI sprite sheet (seeds 1+7, on-chain source, the ×16 degraded
  upscale = the realistic input), toggles: SQUARE↔HEX, POINTY↔FLAT,
  DIFFUSE↔ORDERED↔OFF, palette size, density. Square mode is the classic
  baseline (serpentine Floyd–Steinberg) — untouched, for comparison.
- `dist/` is generated; the `.ts` modules are the source of truth.

Toolchain: the mirror's own local `tsc` binary (on-disk, nothing installed,
no network). Lane: `lane/hex`.
