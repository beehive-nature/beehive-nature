Language costs and the PR bottleneck

The original Python choice lacked comparative evidence. This audit measures the retained implementations, reproduces missing integrity checks, and separates controller overhead from CI waiting and repeated work.

What the evidence can attribute

The user's reported lost workdays are not dismissed. This dataset cannot price them or attribute them to deliberate targeting.

Performance, with uncertainty

Inventory saving: 62.90 ms, 95% interval 59.13–67.11 ms. Law-controller saving: 1,619.82 ms, interval 1,495.06–1,789.10 ms. Both adjusted p-values are about 0.00020. These are local implementation measurements; they do not rank every program in a language.

The first inventory pilot had unequal filesystem placement. It is preserved and excluded. A second pilot exposed an external timing-wrapper floor; the final run uses Rust supervision, with measured no-op overhead of 1.38–1.88 ms. All datasets are retained.

Security controls tested directly

Rust added two controls absent from the original Python implementation. Python could implement both too. Eight selected mutation cases do not estimate a population-wide vulnerability rate or prove complete security.

Where CI time went

Five duplicated feature-push proof workflows consumed 46m16s of job execution on one candidate. This is runner occupancy, not necessarily the same amount of added PR elapsed time. The October 19 outage cannot explain October 16–17 waits.

PR calendar time increased in the retained cohorts

The collection contains 475 PRs. There are 34 unresolved September PRs and 14 unresolved October PRs at the cutoff; they are excluded from merged-duration quantiles and counted separately. No July/August PR records were returned. Calendar time includes development and review as well as CI.

What remains open

The lane now uses Rust tooling and static presentation. The original Python code, pilot results and raw evidence are retained. This does not migrate the entire repository, decentralize existing hosted CI, establish malicious intent, or demonstrate 10 billion active unique humans and 1,000-year continuity. Each remains a separate acceptance question.
