# SPEC-A-NAMES-1 — House Mark System & Heraldry Usage Law

## §heraldry — one mark per job

The house of von Zutphen carries FOUR marks, each with exactly one job. The right mark for the wrong surface is a violation of this law.

| mark | file | job |
|---|---|---|
| **ACHIEVEMENT** | `assets/house/house-achievement.svg` (+ `.png`) | ceremony, blazon pages, the dynasty root page. The full nine-quarter shield with supporters, crest, coronet and compartment. |
| **ROUNDEL** | `assets/house/house-seal-roundel.svg` (+ `.png`) | favicon, chips, small surfaces, wax/coin impressions. The working mark — carries 北方國王 above the bee, orbits exit left and right. |
| **LOCKUP** | `assets/house/house-lockup-banner.png` | signatures, letterheads, banners. The horizontal arrangement. |
| **AVATAR** | `assets/house/house-avatar-square.png` | profiles, social. The square crop. |

### RULES

1. **Never crop the achievement to make a small mark — use the roundel.** The achievement is the ceremony; the roundel is the working hand.
2. The prior seals (`assets/seals/house-crest-von-zutphen-DESIGN.svg/png`) remain in history — promote, don't erase. They are the blazon page's art.
3. Colour comes from `docs/tokens.css`: `--rose` (#C41E3A) for the garden red; gold from `--gold`; no new hues without a token mint.
4. Every surface that carries a mark must carry its **word** — D-1 binds: colour never operates alone.
