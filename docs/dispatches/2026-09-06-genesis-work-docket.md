target, not an achieved property to advertise.

## Return contract

Each slice returns its exact base/head, owned paths, implemented behavior,
checks with failures or skips, remaining limits and a committed dispatch.
New/moved surfaces also carry registry, generated atlas and review entries
in the same commit. Before merge, fetch other seats' work and inspect the
combined tree. Production changes carry a receipt and rollback path; laptop
mesh remains off with only the existing expiring SSH window available.

An issue post is a handoff. A claim is receipt of the handoff. A merged commit
is source integration. A verified deployment is a separate receipt. Keep
these states distinct so the founder can see what has actually happened.
