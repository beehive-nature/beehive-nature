## #505 re-run — method + numbers

**Method honesty first.** The OCI any/any stateful ingress is founder-console
side; the fragment-dropping condition was reproduced ON THE HOST at the netdev
ingress hook: `nft add rule netdev fragdrop ingress ip frag-off & 0x1fff != 0
counter drop` on enp0s6 — non-initial fragments dropped BEFORE kernel
reassembly, the same tails a stateful OCI port rule discards. Two measured
gotchas: `iptables -A INPUT -f` is inert for local delivery (nf_defrag_ipv4
reassembles before INPUT — peers kept connecting with it in place; the raw
table likewise), and tcpdump taps before netfilter so pcaps still show dropped
tails.

**A/B, same host, same filter, fresh-restart windows (frag pcap filter
`ip[6:2] & 0x3fff != 0`):**

| | v0.41.3 (old) | v0.45.0 (new) |
|---|---|---|
| peers after restart | 24-25 @ +100s | 25 @ +55s, 26-27 @ +110-130s |
| outbound fragments | 4,004 pkts / **1,179 oversized 4,096B datagrams** in 100s, incl. bootstraps (:443/:6483) | **0** (one unfiltered window: 18, all to one legacy peer, none to bootstraps) |
| inbound fragments | 0 | 68 pkts — all ONE legacy Starlink peer |
| bootstrap handshakes | 4 IPs established | 4 IPs established (142.93.199.50 + 147.182.234.192 both :443 AND :5483/:6483; 65.21.157.229 + 116.203.101.172 :5483/:6483); SG/JP not dialled in either run |

emits no oversized handshake datagrams. Residual ecosystem risk measured live:
