## Shared interaction contract

[register.js](../../surfaces/register.js), `readingRoom()`, opts in only when a page authors both arrival compositions and a page-owned stage attribute. New bee uses a cream canvas, system typography, large choices and still illustration. Raver uses page-specific SVG scenes, emotional copy and space for imagery. Purple communicates humans, teal AI, green biomass; evidence graphics retain their page-owned palettes and labels.

The new overview control returns from deeper content and restores focus. First actions move keyboard focus into the revealed content. Each page retains its own stages and disclosures across view changes. Motion can be paused, retains its pose when views change, and respects the operating system's reduced-motion setting. Essential controls do not depend on localStorage succeeding.

[tour.js](../../surfaces/tour.js) places the full estate directory in a native disclosure below these pages' content. The language and view controls stay at the top. External links keep the existing new-tab rule. Cache versions are advanced through the generated hub and existing tour consumers; these one-line loader changes are not additional page redesigns. Frozen `forge/orbit.html` remains untouched.
