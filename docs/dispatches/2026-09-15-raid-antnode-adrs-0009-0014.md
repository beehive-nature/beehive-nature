**Pricing-law check (ADR-0013 vs our 2026-08-29 read):** the quote function
itself is unchanged — `price_per_record(n) = 0.00390625 + 0.03515625 ×
(n/6000)²` ANT, 3× upper-median, padding to power-of-two all still stand.
What 0013 adds is a compatibility layer: settlement arithmetic is now
versioned per request so an old client cannot pay into a refusal. Our
citations stay valid; new citations of the 3× rule should note "settlement
versioned per ADR-0013 (Proposed)".

**Operator laws banked:**
1. Never wipe an ant-node data dir to reclaim disk — under LMDB it "works"
   once and costs the network real replicas (ADR-0014's whole reason to be).
2. Migration headroom: a store migration needs `free ≥ live payload` — check
   before upgrading when 0014 lands.
3. First-start WARN storms about holderless keys are a known unconverged-
   routing artifact (ADR-0012), not local breakage.
4. Auto-upgrade selects purely by semver over GitHub release tags — channels,
   not GitHub's prerelease/latest flags, are the safety (ADR-0010); our nodes
   stay upgrade-pinned by policy regardless.
