# FABLE STANDING LAWS — VERBATIM PASTE FOR CLAUDE.md §2
**Source of truth:** the Fable research-seat ledger. This file mirrors it; on conflict, the ledger wins.
**Date:** 2026-08-07

1. **Receipt rule:** no task is done without the pasted command and its real unedited output. No ✅ without a receipt.
2. **Stub law (§0.7):** unfinished code must look unfinished to the toolchain — no `#[allow(dead_code)]`, no underscore-silencing, no comment prettier than the truth. §0.7 bars *silencing*, not *not-shipping*: `#[cfg]` gating that removes code from the artifact is lawful.
3. **Audit two-gates:** Gate 1 (blocking) — every reported advisory proven absent from the default build via `cargo tree -e normal -i <crate>`. Gate 2 (recorded) — raw `cargo audit` output verbatim, every advisory owned by name with a clearing condition. No `--ignore`, ever.
4. **Security-language ceiling:** never stronger than "sound by construction / isolated by design."
5. **Cite or stop:** any Zano crypto claim cites the hyle-team source file/function, or is marked UNVERIFIED and work stops there.
6. **Ruled decisions are not re-asked** — the ledger and RULINGS docs are canon; check them before proposing.
7. **Machine-seat attestation (ORDERS-1):** no machine seat emits `Signed-off-by:` under its own identity; Seat 3 appends the founder's trailer only on merges King Bee explicitly gated; seats are credited via `Co-authored-by:`. (v0.8 pending founder ratification.)
8. **Scope defense:** unsolicited features or architecture → "That is out of scope. Execute the prompt as written."
8d. **THE HARDLINE (ADOPTED 2026-08-08, founder ruling).** **BNR/founder funding must never be the gate on how many users can exist. People pay their own way in BNR.** Any option whose cost curve makes BNR or the founder the bottleneck on user count is **DISQUALIFIED BY CONSTRUCTION**, however elegant — applied *before* merit evaluation, not weighed against it. The one-line test any seat can apply without a founder round-trip: **"does the cost of the ten-billionth user land on BNR?"** If yes, stop. *Applied:* sponsored/metered DEAD ($600M–$1.2B/yr in perpetuity is the gate by definition); credit systems survive **only** where users buy the credits.
8e. **FULL FEATURE SURFACE, NOT ONE ELECTED MECHANISM (ADOPTED 2026-08-08, founder ruling).** *"Why do we keep trying to pick one option for things. Build out fastidious but full features."* Build the **full, user-selectable surface** rather than electing one mechanism — as already done for visibility (private/parent/public) and dual-currency (b for compute, stable for service). **LAW 8d disciplines this menu:** options multiply, but **every option must let the user pay their own way.** The two are complements — 8e expands the surface, 8d bounds what may enter it. Without 8d, a BNR-funded option re-enters as "just one more choice."
8f. **SUMMARY THAT IS TRUE ALONE, DEPTH THAT IS REACHABLE (ADOPTED 2026-08-08, founder ruling — adoption UX).** Two tiers: **(1)** the minimum TRUE things needed to decide, plain and up front, **sufficient alone**; **(2)** full statistics/evidence one level down, **real evidence**. Forbidden: a tier-1 that only makes sense after tier-2 (**a teaser, not a kernel**), and a tier-2 that is marketing expansion (**not depth**). Third independent instance of one shape — spend-receipt UX, informed consent, BN EDU — hence named rather than re-derived a fourth time.
8k. **A QUERY THAT CANNOT RUN IS NOT A QUERY THAT ANSWERED "NO" (STANDING LAW 2026-08-09, founder ruling).** Before trusting a negative result, **prove the probe could have returned a positive.** *Earned three times independently in one session:* a phantom empty mailbox, a phantom dead vault, and Code's scope-emptiness guard. **Cousin (Code, adopted):** *a comparison against a missing baseline is not a comparison* — record the baseline so the next check has something real to compare to. *(Recorded 2026-08-09 — this law was adopted and cited in several post-ops before it was written into this file. The gap is itself an instance of the drift this register exists to prevent.)*
8n. **A PASSING TEST SUITE IS NOT EVIDENCE A CONSTRUCTION IS SOUND — IT IS EVIDENCE IT SURVIVES THE CASES YOU THOUGHT OF (STANDING LAW 2026-08-09, founder ruling).** **Every consensus-critical choice — hash construction, encoding, ordering, tag values, tie-breaks — gets a REVIEW pass against known attack classes and prior art, SEPARATE FROM and IN ADDITION TO its test suite.** *Earned:* Cowork's R6 prototype passed 9/9 while carrying **CVE-2012-2459**, because no failure mode modelled set-collision. **Testing alone cannot find what it does not model.** *(Numbered 8n, not 8m: the founder's adopting message said "LAW 8m", but 8m was already in force as THE CORE MEASURE DECIDES. Flagged rather than silently overwritten — a renumber that quietly displaces a live law is exactly the failure this file exists to prevent. Founder may renumber.)*
8l. **SEQUENCERS SERIALIZE ANCHORS — WAIT FOR INCLUSION BEFORE PUSHING THE NEXT (STANDING LAW 2026-08-09, measured).** A chain-linked anchor compares `prev_root` against the node's **speculative** state. Push faster than block production and the link check fails **even when every payload is correct** — the error reads as data corruption and is not. *Measured:* E1–E4 landed in consecutive 0.5 s blocks; E5 was refused, then succeeded **byte-identical** two minutes later. **The wait belongs inside the sequencer, never left to the caller.**
8m. **THE CORE MEASURE DECIDES; ESCALATE ONLY WHAT IT CANNOT (STANDING LAW 2026-08-09, Seat 1 under the core measure).** Seats stop stacking "one word each" items. **If the measure resolves it, rule it and dispatch** — as `prev_root` and `epoch_time` were ruled. **Escalate only:** a values call · a name · a number with no derivable basis · a genuine fork where **both** options pass the measure. *Rationale:* a founder queue of derivable questions is itself a scaling failure — the thing the measure exists to prevent.
8i. **DEPLOY AUTHORITY IS A CUSTOM PERMISSION, NOT `@active` (STANDING LAW 2026-08-08, founder ruling).** **Threshold-1 with two weight-1 keys means EITHER KEY ALONE** can replace the code, move the balance, or change the permission again. **Accepted on Jungle only** (disposable account; deploy is the milestone). **For anything non-testnet: deploy authority is a CUSTOM PERMISSION `linkauth`'d to `setcode`/`setabi`/`buyram` ONLY.** *Reasoning, which is the rule:* it is the shape that survives being copied — **and testnet patterns get copied.** A convenience granted on a throwaway becomes the default on the account that matters, because nobody re-derives the permission model at deploy time.
8j. **ANTELOPE SORTS AUTHORITY KEYS BY SERIALIZED KEY BYTES, NOT BASE58 TEXT (2026-08-08, measured).** A key set whose byte order and text order diverge is rejected as **"invalid authority"** — an error that points at the authority, not at the sort, so it misdirects. Sort on the **decoded 33-byte compressed key**, never the `EOS…` string.
8h. **A KEY-DERIVATION CHANGE IS A DATA MIGRATION — EVEN WHEN THE STRUCT IS BYTE-IDENTICAL (STANDING LAW 2026-08-08, all seats).** **Antelope stores the primary key at WRITE time and never recomputes it.** So changing how a key is *derived* leaves every previously-written row indexed under the old derivation: the struct diffs clean, the ABI diffs clean, and the rows are still wrong. **Treat any derivation change as a migration and say so in the post-op note**, whatever the struct looks like. *Earned:* Code's ring work, where the derived-slot change would have silently orphaned existing rows. **The tell to watch for: "the struct didn't change, so there's nothing to migrate" — that sentence is the defect.**
8g. **PUBLIC CONSTANTS ARE ANNOTATED, NEVER BYPASSED (STANDING GUIDANCE 2026-08-08, all seats).** The secret-scan hook blocks any 48+ char hex run, because **a public chain id and a private key are the same shape to a scanner.** When the run is genuinely public — chain id, block id, tx hash, dependency checksum — **annotate it on the same line (`PUBLIC-CONSTANT`, or `TESTNET-ONLY` for a deliberate test vector). NEVER `--no-verify`.** *Reasoning, which is the load-bearing part:* reaching for the bypass because "it's obviously just a chain id" is precisely how a real key eventually rides through on the same judgement. The annotation costs one comment; the habit it replaces costs everything once. *Earned:* Cowork's post-op note was blocked on the Jungle4 chain id and annotated rather than bypassed.
8c. **PROVENANCE SURVIVES THE RELAY (ADOPTED 2026-08-08, founder ruling).** A claim's **author travels with the claim**. **ADDRESSED-TO IS NEVER REWRITTEN AS ORIGINATED-BY.** Two duties: when you **relay** another seat's work, **name who made each claim**; when you are **credited with something you did not say, FLAG rather than absorb**. Companion to LAW 8a — **8a stamps WHERE a claim came from; 8c stamps WHO MADE IT.** *Earned:* two same-class errors — the escrow line attributed to Code that was the founder's aside, and the four earn-ANT questions authored by Fable, later described as Code's. Both caught by the miscredited seat flagging rather than absorbing.
8b. **Adapter-rail selection is UPSTREAM of design (ADOPTED 2026-08-08).** Measure **depth against any candidate rail BEFORE choosing it** — never design a mechanism and then discover the rail cannot carry it. *Earned:* three independent layers converged on the same conclusion — **supply binds; price mechanisms do not move it.** A rail that cannot carry the traffic makes every downstream design question moot, so rail selection is asked first, not last.
8a. **CRATE + REF stamping (ADOPTED 2026-08-08).** Every source claim carries the **crate and the ref it was read at** — `crate @ pin`, the same discipline already applied to tree heads. *Earned, not theorized:* three of one night's apparent disagreements were **"different layer" or "different pin," not real conflicts** (goose read `ant-core @ ant-client 81a0a24`; Code read `evmlib @ main` — both correct, reconciled only once the stamps were compared). An unstamped source claim is not verifiable and must not enter a spec.
9. **Cadence:** one phase per session, one file per prompt, explicit acceptance criteria, commit checkpoints immediately; exact compiler output for fixes only.
10. **False-signal law (k001 class):** a false comment or claim is deleted, not patched; never let any signal be prettier than the truth; fix forward, never rewrite public history.
11. **Check before acting:** verify whether a thing already landed before executing an instruction to do it.
12. **Digests:** Git Bash or WSL `sha256sum` on raw stdin; never PowerShell pipes.
