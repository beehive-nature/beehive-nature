# BATCH RAID 2 — nine targets — RULE-vs-SERVER SORT + LANE MAP — 2026-09-03

Reading raid (Cowork seat), founder's pick "queue all nine, same batch shape." Nine repos read at
source on 2026-09-03; HEAD hashes and licences in VERIFIED-FACTS A80–A88. Code judged, never the
coder. Prior record: Firecrawl (from the same list) is already RULED and not re-raided; SearXNG and
LiteLLM had been named in earlier rulings without a read — this is that read.

**Sort rule.** RULE = runs with no operator-run box (local binary/process, local model, pure library,
local store). SERVER = needs a third party's hosted service. **SERVER AT THE ROOT** is flagged where
the default path calls a vendor even if a local path exists.

## 2 · microsoft/graphrag — MIT (A81)

extraction with NLTK/spaCy noun phrases (`methods.md:19-29`). Query: local search = 1 embedding + 1
completion; **global search = one completion per community-report batch + a reduce call — N+1, N grows
with the corpus** (`global_search/search.py:120-135`). Storage: file/parquet + LanceDB by default;
Azure blob/cosmos/AI Search optional. No telemetry (grep clean).

## What stays behind (SERVER class — boarding facts)

Zed's cloud (Zed AI default, Zeta, collab/LiveKit, extension registry, `/telemetry/events` + minidumps,
auto-update); Trivy's `check.trivy.dev` ping and un-mirrored DB pulls; LiteLLM's `enterprise/`,
