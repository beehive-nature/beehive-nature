# NINE FLAGS — THE PICTURE (one screen)

Nine projects read cover to cover. Two corrections up front: **Audacity 4.0 is real** — released today,
not a rumour — and the classroom project is called **OpenMAIC**, not OpenMAI.

| # | project | what a member gets | stays behind | recommended verdict |
|---|---|---|---|---|
| 1 | **Audacity 4** (audio editor) | A serious sound editor a member can run on their own machine; opens and hosts the usual effect plugins | The plugin store, the cloud upload, the update pinger and crash reporter; a Windows build needs a proprietary kit from Steinberg. Its licence is fine as a neighbour, never as a part of the hive's own core | **Use it as a tool. Lift nothing.** |
| 2 | **OpenMAIC** (classroom) | Lessons that build themselves as slides + quizzes + exercises, in a shape the hive can store and grade; multiple-choice graded on the member's box, written answers graded by the model; runs on the local engine today | Vendor search and vendor voices — both have local substitutes | **TAKE** — the lesson shape and the grading, into BN EDU |
| 3 | **DeepTutor** (tutor) | A tutor that reads, researches and *remembers* — and its memory is plain files in three layers (what happened → what it means → who you are), which is exactly how the hive keeps a member's context | Its default model is a vendor's; six local engines are already in its list | **TAKE** — the memory layout and the tutor loop, into BN EDU |
| 4 | **AirI** (voice companion) | Listen → understand → speak → animated face, all inside the browser, no vendor in the loop; mic **off** until the member turns it on, nothing sent until they say so — already matches the opt-in law | The project's own cloud, its analytics (on in their builds — off in ours), the Discord/Telegram bots, and a proprietary face format we skip | **TAKE** — self-built only, opt-in kept, into the voice layer and Luna's lane |
| 5 | **Letta** (stateful agents) | The idea of an agent that carries its memory in named blocks — and can be **exported as one file** and brought back anywhere: the "keep your agent" promise in file form | The code is archived; the default model is their cloud | **PATTERN** — blocks + the agent file, into the private context store |
| 6 | **OpenViking** (context database) | A memory that is a **filing cabinet first, search index second** — every folder carries its own short summary — the closest thing to the hive's own context-store shape | Its licence bites anyone who serves a modified copy online, so it never goes inside the moat; its default embedder is ByteDance's cloud and must be switched off first | **PATTERN** — the shape; the code only as a member's own standalone store |
| 7 | **Headroom** (context compression) | **The one that saves money**: shrinks what the model reads by ~41 % on its own reproducible test, with no model call and nothing lost that can't be pulled back — sits straight in front of the meter | It phones home by default (one switch turns that off); the "50–90 %" claim on the tin is not what the test shows | **TAKE** — in offline mode, in front of the meter |
| 8 | **GenOffice** (docs/sheets/slides) | Three real editors in open formats — Word, Excel and PowerPoint files — that never touch the network to edit, plus an AI seat that can be pointed at the hive's own engine | The AI is wired to Genspark's cloud by default and quietly falls back to it — that wire gets cut; analytics and auto-update on by default | **TAKE the editors · LEAVE the AI wire** — the PCi suite target |
| 9 | **AI Hedge Fund** | One pattern: many opinions → one bounded number → hard limits → the model never pulls the trigger. (No actual "debate" exists in the code.) | Everything financial: the paid data feed, the backtester, any broker | **PATTERN ONLY. Every financial piece: LEAVE.** |

Three switches to flip before any of these run on a member's box: OpenViking's embedder, GenOffice's
AI fallback, Headroom's beacon. Everything marked TAKE runs the day the makers' servers stop.
