# BATCH RAID — nine targets — RULE-vs-SERVER SORT + LANE MAP — 2026-09-03

Reading raid (Cowork seat). Nine repos read at source on 2026-09-03; HEAD hashes and licences
in VERIFIED-FACTS A71–A79. Code judged, never the coder. Two premises corrected at intake:
**Audacity 4.0 IS released** (tag `Audacity-4.0.0` @ `4c177d43`, 2026-09-03, GitHub "latest",
not pre-release — A71), and the classroom repo is **OpenMAIC**, not "OpenMAI" (A72).

**Sort rule.** RULE = runs with no operator-run box (local process, local model, desktop app,
pure library, local store). SERVER = needs a third party's hosted service. **SERVER AT THE ROOT**
is flagged where the *default* core path calls a vendor cloud even if a local path exists.

## What stays behind (SERVER class — boarding facts)

search everywhere; `api.airi.build`, PostHog and the platform bots (AirI); `letta-free` / `inference.letta.com`
