# PNPM v12 (Rust rewrite) — RULE-vs-SERVER SORT — 2026-09-05

Reading raid (Cowork seat), founder flag: The Register 2026-09-04 "pnpm recast in Rust". Source read at
pnpm/pnpm `3c1af785` (2026-09-05); tag `v12.0.0` = `2f62913c`. Licences in VERIFIED-FACTS A89. Code judged, never the coder.

**Verdict in one line.** The CLI is RULE and clean — a self-contained native binary (no embedded Node), same
store layout and lockfile as v11, `--offline` honoured, no telemetry. Two things to know: the `pnpr/` registry
server is **NOT open source** (PolyForm Shield 1.0.0 — source-available with a noncompete), and the only
phone-home is the daily update-notifier (default on, one switch). Seat: ops tooling (same shelf as uv).
