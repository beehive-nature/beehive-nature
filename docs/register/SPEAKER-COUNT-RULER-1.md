## The law of this register

**The ruler is a register of records, not a lookup.** Every entry carries: source + date
+ method + **macrolanguage classification** (pinned per record — Arabic aggregates a
dialect continuum; Hindi/Urdu swings on lump-vs-split; an unpinned classification makes
any gate number mush) + **native and L2 separated, never blended**. Disagreements between
statements are **rendered, never resolved** — multiple sourced values stand side by side
and the register recomputes on schedule (weekly standing query; failures recorded as
failures, never absences).
