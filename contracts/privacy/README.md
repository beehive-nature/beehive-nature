# contracts/privacy — the estate-run privacy layer (Lane: SPEC-PRIVACY-1)

- `verify_min.cpp` — GENERATED by `gen_verifier.js`: the minimal Groth16-shape
  verifier. One `alt_bn128_pair` call over 4 pairs = the production Groth16
  verification cost. Actions: `verify` (valid toy instance — must pass) and
  `verifybad` (broken tuple — its success ASSERTS the chain returned false,
  i.e. invalid proofs reject). Regenerate: `node gen_verifier.js`.
- Deployed + measured on Spring v1.2.2 (see SPEC-PRIVACY-1 §m1-receipt):
  billed cpu_usage_us ≈ 5.0–6.4 ms (median ~6.1 ms), status executed.
- Toolchain: CDT 4.1.1 (`cdt-cpp -O3 -o verifymin.wasm -abigen verify_min.cpp`),
  chain activation path + the minibios bootstrap in SPEC-PRIVACY-1.
- M3 (private note) builds here AFTER the M2 fork is ruled.
